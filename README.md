# Salma Mohamed — React portfolio

A responsive portfolio built with React, Vite, and Motion for React.

## Run locally

1. Install Node.js (18.2+ React compatibility; Node 20+ recommended for current Vite).
2. From this folder run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.
4. Use `npm run build` to create a production build in `dist/`.

## Before publishing

- Replace `hello@salma.dev` with Salma's preferred contact email.
- Add the real LinkedIn and GitHub profile URLs.
- Confirm the education timeline dates and all project copy.
- Update the SEO title and description if needed.

The portfolio uses Motion (`motion/react`) for the reveal, hover, and orbit animations. It respects the device's reduced-motion setting.
